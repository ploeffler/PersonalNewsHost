Optional: Ein Fine-grained Personal Access Token mit Zugriff ausschließlich auf ploeffler/PersonalNewsHost und Berechtigung Contents: Read and write ermöglicht das Speichern ohne Download. Der Token wird nur für diese Sitzung im Eingabefeld gehalten, nicht gespeichert oder ins Repository übertragen. Verwende keinen klassischen Token mit breiten Rechten. Auf einem gemeinsam genutzten Gerät besser die Download-Funktion verwenden.

Wie werden Änderungen aktiv?
