Automatische Nachrichtensendungen

GitHub Actions prüft stündlich ungefähr um Minute 17 (UTC), ob die gewählte Stunde fällig ist. Die tatsächliche Ausführung kann sich durch GitHub verzögern oder in Einzelfällen ausfallen. Startstunde bedeutet Stundenraster, keine minutengenaue Startzeit. Die gewählte Zeitzone berücksichtigt Sommer- und Winterzeit. Doppelte Stunden im Herbst werden nur einmal ausgeführt; entfallende Stunden im Frühjahr werden übersprungen. Manuelle Workflow-Starts bleiben auch bei deaktivierter Automatik möglich.
